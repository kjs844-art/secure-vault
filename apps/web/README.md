# Web App

React와 TypeScript 기반 편의 클라이언트입니다. Rust/WASM 암호화 코어를 사용하고 IndexedDB에는 암호문만 저장합니다.

금고 origin에는 광고, 분석, 채팅, 임의의 제3자 JavaScript를 포함하지 않습니다.

## 지금 들어 있는 것

랜딩 페이지만 구현돼 있습니다. 금고 본체(잠금 해제, 목록, 검색, 상세)는 아직 없습니다.

```
src/landing/VaultField.tsx   3D 배경 — 흩어진 정체성
src/App.tsx                  히어로, 떠 있는 카드
src/index.css                디자인 토큰과 레이아웃
src/fonts.ts                 자체 호스팅 폰트
```

## 명령

```bash
npm run dev         # 개발 서버
npm run build       # 프로덕션 빌드
npm run typecheck   # 타입 검사
npm run preview     # 빌드 결과 미리보기
npm run screenshot  # 데스크톱·와이드·모바일 스크린샷 (미리보기 서버가 떠 있어야 함)
```

스크린샷은 `TARGET`으로 주소를, `OUT`으로 저장 위치를, `CHROME_PATH`로 Chromium 실행 파일을 지정할 수 있습니다.

## 디자인 결정

**3D는 구역을 나눠 씁니다.** 랜딩과 연결 지도에서만 3D와 연출을 쓰고, 금고 내부(목록·검색·상세)는
모션 150ms 이하에 3D 없이 갑니다. API 키 하나 찾는 데 전환 효과가 끼면 매일 쓰는 도구가 아니라
전시물이 됩니다.

**배경은 장식이 아니라 논증입니다.** 중심의 빛이 사용자, 안쪽 궤도는 관리되는 연결,
바깥으로 갈수록 희미해지고 중심과의 실이 끊깁니다. 제품이 푸는 문제를 한 장면으로 진술합니다.

**잠금 상태가 색입니다.** 잠긴 것은 차가운 무채색, 열린 것은 앰버. 색이 보안 모델을 가르칩니다.

**가림 장치(redaction)가 시그니처입니다.** 값 위에 덮인 앰버 바가 상호작용 시 걷힙니다.
보안 제품만 쓸 수 있는 그래픽 장치입니다.

**자격증명은 모노스페이스 전용입니다.** 값·식별자는 `IBM Plex Mono`, 설명 문장은 `IBM Plex Sans KR`.
사람이 읽는 것과 기계가 읽는 것을 서체로 가릅니다.

## 알아둘 제약

- **폰트를 자체 호스팅합니다.** 금고 제품이 매 접속마다 외부 폰트 서버에 요청을 보내면 그 서버가
  방문 사실을 알게 됩니다. 배포 전 실사용 글리프만 서브셋해야 합니다 — 한글 웨이트 하나가 500KB입니다.
- **번들이 큽니다** (gzip 약 330KB). 대부분 three.js입니다. 금고 본체를 붙일 때 3D를 랜딩 청크로
  분리해야 합니다. 금고 화면은 three.js가 필요 없습니다.
- 한글 제목에는 `word-break: keep-all`이 필수입니다. 없으면 낱말 중간에서 줄이 바뀝니다.
- 모든 값은 합성입니다. 서비스명은 범주 예시일 뿐 실제 계정과 무관합니다.
