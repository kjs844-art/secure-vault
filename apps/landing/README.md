# Landing

공개 랜딩 페이지입니다. **금고 앱(`apps/web`)과 별개의 앱**이며 같은 origin에서 서빙하지 않습니다 —
보안 아키텍처가 마케팅 코드와 금고 코드의 origin 분리를 요구하기 때문입니다.
그래서 여기서는 3D 라이브러리와 연출을 자유롭게 쓰고, 금고 앱에는 하나도 들이지 않습니다.

## 지금 들어 있는 것

첫 화면 하나입니다. 글 없이 **유리 열쇠** 한 자루만 떠 있고, 스크롤하면 열쇠가 비켜서며 첫 문장이 뜹니다.

```
src/landing/GlassKey.tsx   유리 열쇠 씬 — 굴절·분산, 조명판 환경, 카메라 드리프트
src/App.tsx                첫 화면과 첫 챕터
src/index.css              토큰과 레이아웃
src/fonts.ts               자체 호스팅 폰트
```

## 처음 실행할 때

Node.js 20.19 이상이 필요합니다 (22 LTS 권장). **관리자 권한은 필요 없습니다.**

```bash
cd apps/web
npm install
npm run dev
```

터미널에 뜨는 `http://localhost:5173` 을 브라우저에서 엽니다.

Windows PowerShell에서 `npm.ps1 ... 스크립트를 실행할 수 없습니다` 오류가 나면 실행 정책 문제입니다.
관리자 권한이 아니라 아래 한 줄로 풉니다.

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 명령

```bash
npm run dev         # 개발 서버
npm run build       # 프로덕션 빌드
npm run typecheck   # 타입 검사
npm run preview     # 빌드 결과 미리보기
npm run screenshot  # 데스크톱·와이드·모바일 스크린샷 (미리보기 서버가 떠 있어야 함)
npm run build:single # 폰트·JS까지 한 파일에 넣은 미리보기 빌드 → dist-single/ (더블클릭으로 열림)
```

스크린샷은 `TARGET`으로 주소를, `OUT`으로 저장 위치를, `CHROME_PATH`로 Chromium 실행 파일을 지정할 수 있습니다.

## 디자인 결정

**첫 화면에는 글이 없습니다.** 열쇠 하나가 전부입니다. 제품이 무엇인지 말하기 전에 무엇처럼 느껴지는지를 먼저 보여 줍니다.

**열쇠는 유리입니다.** 속이 다 들여다보이는데도 열쇠입니다 — 제로지식을 형태로 말합니다. 색은 따로 칠하지 않고
유리 가장자리의 파장별 분산(무지개)만 냅니다. 굴절은 스넬 법칙, 분산은 파장 의존 — drei의
`MeshTransmissionMaterial`이 둘 다 합니다.

**손잡이 안에 그래프가 있습니다.** 허브 하나와 노드 여섯. Key + Atlas. 로고가 곧 제품 설명입니다.

**3D는 이 랜딩에만 있습니다.** 금고 앱(`apps/web`)은 별도 origin이고 3D를 쓰지 않습니다.

**DOM과 WebGL은 분리돼 있습니다.** 캔버스는 고정, 글은 그 위를 흘러갑니다. 스크롤 값 하나만 씬에 건네고
씬이 열쇠 위치·크기를 화면 비율에 맞춰 정합니다.

**자격증명은 모노스페이스, 라틴 표시어는 Space Grotesk, 한글은 IBM Plex Sans KR.**

## 알아둘 제약

- **폰트를 자체 호스팅합니다.** 금고 제품이 매 접속마다 외부 폰트 서버에 요청을 보내면 그 서버가
  방문 사실을 알게 됩니다. 배포 전 실사용 글리프만 서브셋해야 합니다 — 한글 웨이트 하나가 500KB입니다.
- **번들이 큽니다** (gzip 약 330KB). 대부분 three.js입니다. 금고 본체를 붙일 때 3D를 랜딩 청크로
  분리해야 합니다. 금고 화면은 three.js가 필요 없습니다.
- 한글 제목에는 `word-break: keep-all`이 필수입니다. 없으면 낱말 중간에서 줄이 바뀝니다.
- 유리 재질은 무겁습니다 (`backside` 2패스 + 샘플 6). 소프트웨어 렌더러에서는 프레임당 수 초가 걸리므로
  스크린샷은 1배 해상도로 찍습니다. 실제 GPU에서는 문제없습니다.
- `KeyAtlas`는 내부 작업명입니다. 최종 이름·상표·도메인은 별도 조사 뒤 정합니다.
- 모든 값은 합성입니다. 서비스명은 범주 예시일 뿐 실제 계정과 무관합니다.
