# 출시 준비 체크리스트

이 문서는 기능 출시 단계를 섞지 않기 위한 gate 문서입니다. 이 worktree의 합성 시연판은 실제 Secret, 로그인, 결제, 운영 DB를 포함하지 않습니다.

## 1. 합성 시연판

- [ ] 합성 데이터로 핵심 화면 흐름이 재현된다.
- [ ] empty, loading, error 상태가 화면 설계에 기록된다.
- [ ] 내부 Markdown 상대 링크 검사가 통과한다.
- [ ] 360px 폭에서 문서화된 UI 감사가 완료된다.
- [ ] 사용자가 할 일: 합성 데이터만 사용하고 시연 범위를 승인한다.
- [ ] 에이전트가 할 일: 문서·fixture·정적 코드 검사를 반복 가능하게 유지한다.

## 2. Private alpha

- [ ] 초대된 테스터와 피드백 채널이 정해진다.
- [ ] 데이터 삭제·복구 정책과 지원 담당자가 사용자에게 안내된다.
- [ ] 실제 계정 연동 없이도 안전한 테스트 경로가 제공된다.
- [ ] 사용자가 할 일: 테스터 초대, 피드백 범위와 성공 기준 결정.
- [ ] 에이전트가 할 일: 재현 절차와 알려진 제한을 기록하고 회귀 검사를 유지.

## 3. 실제 Secret 제한 beta

- [ ] 위협 모델과 Secret 노출 경계가 별도 보안 리뷰를 통과한다.
- [ ] 인증, 권한, 암호화, 복구, 세션, 저장 계약의 운영 설계가 승인된다.
- [ ] 운영 로그·분석에 Secret이 남지 않음을 검증한다.
- [ ] 사용자 가입·약관·개인정보·지원 책임자가 결정된다.
- [ ] 사용자가 할 일: 실제 Secret 사용 승인, 계정·정책·지원 결정.
- [ ] 에이전트가 할 일: 승인된 범위의 테스트 자동화와 증거 문서화.

## 4. 공개 출시

- [ ] 베타 종료 기준과 중단/롤백 기준이 충족된다.
- [ ] 배포, IAM, 운영 DB, 모니터링, 백업, 장애 대응 소유자가 승인된다.
- [ ] 가격, 결제, 환불, 법적 고지와 고객지원 경로가 확정된다.
- [ ] 보안 및 개인정보 최종 승인 없이 공개하지 않는다.
- [ ] 사용자가 할 일: 출시 승인, 가격·정책·운영 책임 결정.
- [ ] 에이전트가 할 일: 승인된 출시 체크리스트와 검증 결과를 최신 상태로 유지.

## 현재 판정

현재 worktree의 범위는 **합성 시연판 준비 지원**입니다. Private alpha 이후 gate는 미승인입니다. 실제 Secret, 로그인/OAuth, 결제, 배포, 운영 인프라는 이 문서에서 검증하지 않았습니다.
