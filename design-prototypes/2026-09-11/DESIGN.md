# KeyAtlas — 세 가지 디자인 방향

작성: 2026-09-11. 제품명은 working title. 로컬 탐색 시안이며 최종 디자인 시스템이 아닙니다.
Stitch 프로젝트 ID: 없음. 새 시스템 업로드 전 색상·서체·모서리 규칙 확인을 기다립니다.

## 1. Visual Theme & Atmosphere

| 방향 | 분위기 | 주된 사용 위치 |
| --- | --- | --- |
| 01 Monolith | 건축적인 금고 오브제, 어둡고 절제된 프리미엄 | 소개·잠금 화면 + 금고 시안 |
| 02 Quiet Vault | 밝고 정돈된 서랍, 적은 시각 자극, 편한 읽기 | 기본 금고·계정 관리·모바일 |
| 03 Atlas Network | 정밀한 관계 지도, 키와 사용처의 맥락 | API·MCP 연결 지도·상세 |

추천 조합: 기본 화면은 02, 소개·잠금 화면의 상징은 01, 필요할 때 펼치는 연결 지도는 03.
서로 다른 세 팔레트를 그대로 혼합하지 말고 선택 후 하나의 공통 토큰으로 정리합니다.

## 2. Color Palette & Roles

- 01: 깊은 녹흑색 `#111615` 배경, 회녹색 `#34413B` 구획선, 밝은 라임 `#D8F799` 주요 행동, 아이보리 `#F0F3E9` 본문.
- 02: 따뜻한 아이보리 배경 + 코발트 주요 행동 + 짙은 잉크 본문. 구체적인 현재 값은 02 HTML의 CSS를 기준으로 합니다.
- 03: 그래파이트·청회색 배경 + 구리색 선택 경로 + 밝은 회색 본문. 구체적인 현재 값은 03 HTML의 CSS를 기준으로 합니다.
- 상태는 색만으로 전달하지 않고 `사용자 기록`, `확인 전`, `합성 데이터`라는 글자를 함께 표시합니다.

## 3. Typography Rules

외부 폰트 요청 없이 시스템 기본 글꼴을 사용합니다. 한글은 Malgun Gothic 또는 시스템 한글 폰트,
영문 UI는 Arial/system-ui 계열, 짧은 식별자와 보조 라벨은 시스템 고정폭 글꼴을 씁니다.
실제 제품화 시 한글 본문 크기와 키보드 접근성을 먼저 검증하고 폰트 선택을 확정합니다.

## 4. Component Stylings

- 버튼: 분명한 기본 행동 1개, 보조 행동은 테두리·낮은 강조. 눌러도 아무 일 없는 장식 버튼은 피합니다.
- 카드: 가볍게 둥근 모서리와 절제된 경계. 자료보다 그림자나 애니메이션이 먼저 보이지 않게 합니다.
- 입력: 실제 비밀 입력칸은 만들지 않고 검색창만 사용합니다. 현재 시안은 저장하지 않습니다.
- 원문: 마스킹 → 데모 확인 대화상자 → 가짜 값 잠시 표시 → 재가림 흐름만 제공합니다.
- 연결: `발급처 → 자격증명 → 앱/MCP 사용처`, 그리고 사용자 기록인지 검증된 정보인지 표시합니다.
- 모션: 소개의 짧은 진입 효과만. 데이터 뒤의 지속 회전·파티클·스크롤 강제 이동은 사용하지 않습니다.

## 5. Layout Principles

화면의 핵심 작업은 찾기, 선택, 필요한 원문 확인입니다. 목록/상세 또는 지도/상세를 중심으로 구성합니다.
모바일에서는 패널을 쌓거나 지도를 목록으로 바꾸고, 전체 구조를 억지로 축소하지 않습니다.
실제 비밀 데이터는 WebGL·마케팅 분석·생성형 디자인 도구로 전송하지 않는 구조가 필요합니다.

## Stitch로 이어갈 구조 프롬프트

선택한 디자인 시스템을 프로젝트 수준으로 먼저 설정한 뒤 아래 구조 프롬프트를 사용합니다.
새 화면 생성 프롬프트에 팔레트·서체 토큰을 다시 중복 주입하지 않습니다.

1. 플랫폼: 한글 개인 보안 금고 웹앱, 데스크톱 우선 + 모바일 스택 레이아웃.
2. 헤더: KeyAtlas working title, 검색, 합성 데이터 시안 상태.
3. 사이드바: 전체, 아이디·비밀번호, API 키, MCP; 프로젝트/환경 필터.
4. 본문: 서비스·별칭·사용처 검색, 최근·즐겨찾기, 유형에 맞는 상세.
5. 상세: 발급처, 사용자 기록 사용처, 마스킹된 합성 값, 데모 확인 흐름.
6. 연결 지도: 선택 경로 강조, 목록 대안, 자동 발견·유효성 검증 오해 금지.
7. 푸터: 저장/암호화/인증 미연결, 실제 비밀정보 입력 금지.
