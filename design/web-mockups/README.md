# 웹 클라이언트 화면 목업

`apps/web` 구현 전 단계의 화면 설계입니다. 각 `.dc.html`은 하나의 아트보드이고,
`canvas.json`이 배치와 페이지를 정의합니다. 이 폴더는 설계 자료이며 실행 코드가 아닙니다.

## 화면

| 파일 | 화면 | 구역 |
| --- | --- | --- |
| `Main.dc.html` | 랜딩 — "흩어진 나" | 연출 허용 |
| `Graph.dc.html` | 연결 지도 — 전체 | 3D가 정보 그 자체 |
| `GraphFocus.dc.html` | 연결 지도 — 노드 선택 | 3D가 정보 그 자체 |
| `Login.dc.html` | 계정 로그인 | 모션 절제 |

## 디자인 결정

**3D 구역 분리.** 랜딩과 연결 지도에서만 3D와 연출을 씁니다. 금고 내부(목록·검색·상세)는
모션 150ms 이하, 3D 없음 — 매일 쓰는 노동 공간이기 때문입니다.

**잠금 상태가 색입니다.** 잠긴 상태는 차가운 무채색, 해제된 상태는 앰버가 들어옵니다.
색이 보안 모델을 가르치게 합니다.

**자격증명은 모노스페이스 전용.** 값·식별자·revision 해시는 `IBM Plex Mono`,
설명 문장은 `IBM Plex Sans KR`. 사람이 읽는 것과 기계가 읽는 것을 서체로 분리합니다.

## 문서에서 온 제약

- 계정 인증과 금고 잠금 해제는 절대 같은 화면에 두지 않습니다 (`docs/superpowers/specs` §6)
- 검색 UI는 무엇이 검색 대상이고 무엇이 아닌지 스스로 밝힙니다 (Secret 원문 제외)
- 클립보드 정리는 "보장"이 아니라 "시도"로 표기합니다
- 충돌 해결은 1급 화면입니다. 토스트가 아닙니다
- 모든 화면 상단에 v0alpha1 합성 데이터 경고 배너

## 알려진 근사

캔버스 미리보기는 외부 스크립트를 불러올 수 없어 3D를 CSS 3D 트랜스폼과 SVG로 근사했습니다.
실제 `apps/web` 구현은 React Three Fiber를 전제로 합니다. 목업의 3D는 설계도이지 실물이 아닙니다.

## 데이터

모든 값은 합성입니다. 서비스명은 카테고리 예시일 뿐 실제 계정과 무관합니다.
