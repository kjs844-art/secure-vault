## 추가 요청 반영: 더 절제된 3D 웹·앱 방향

- 메인 화면을 지구본·중앙 금속 자물쇠·서비스 연결 궤도 중심으로 다시 구성했습니다.
- `orbit-globe.js`와 `orbit-globe.css`를 웹과 모바일에서 공유합니다.
- Canvas의 실제 3차원 좌표 투영과 CSS 입체감을 사용한 일러스트입니다. Three.js/WebGL 모델은 아닙니다.
- 30fps 상한, 화면 밖/비표시 정지, 모션 감소 설정과 사용자 재생·정지를 지원합니다.
- 반복 카드/배지를 줄이고 시스템 서체의 크기·굵기·행간·여백을 다시 조정했습니다.
- 모바일은 웹을 축소한 화면이 아니라 인트로 → 금고 목록 → 상세 바텀시트 흐름입니다.
- 네이티브 iOS/Android 앱을 빌드한 것은 아니며, 브라우저에서 확인하는 반응형 앱 시안입니다.

기존 세 시안도 유지했습니다. 비교 화면에서 원하는 시안의 `직접 둘러보기`를 누르세요.
브라우저가 로컬 iframe을 제한하면 개별 HTML을 직접 열어도 됩니다.

- [01 Monolith](01-monolith.html): 입체 금고 오브제와 어두운 프리미엄 분위기.
- [02 Quiet Vault](02-quiet-vault.html): 밝고 읽기 쉬운 기본 금고. 현재 추천안.
- [03 Atlas Network](03-atlas-network.html): API·MCP의 발급처와 사용처를 보는 연결 지도.
- [DESIGN.md](DESIGN.md): 선택 기준, 팔레트 역할, 레이아웃과 Stitch 후속 프롬프트.

모두 실제 HTML/CSS/JavaScript 시안입니다. 디자인 이미지만 붙인 문서는 아닙니다.
가짜 항목 검색·선택·데모 확인 흐름을 포함하며 실제 저장/암호화/생체인증/서비스 연결은 없습니다.
실제 비밀번호와 API 키를 입력하지 마세요. 클립보드 복사 안내도 모의 흐름입니다.

## 참고와 도구

- [Lusion](https://lusion.co/): 공식 소개의 3D·모션·인터랙티브 브랜드 경험을 공간감의 방향으로 참고.
- [Lusion Labs](https://labs.lusion.co/) 및 [WebGL Scroll Sync](https://webgl-scroll-sync.lusion.co/): 실험적인 시각 요소와 화면 콘텐츠의 관계 참고.
- [Linear](https://linear.app/): 공개 제품 소개의 검색/목록/상세 중심 정보 구조 참고.
- [1Password](https://1password.com/developers/secrets-management), [Infisical](https://infisical.com/): 자격증명과 개발 도구 사용 맥락 참고.
- UX Pilot: 커뮤니티 목록을 조회해 SaaS/Fintech/AI 설정 대시보드 종류를 확인했습니다. 유료 템플릿 구매·복제는 하지 않았습니다.
- Stitch: 기존 프로젝트 조회 및 프롬프트/디자인 시스템 지침을 확인했습니다. KeyAtlas 전용 프로젝트가 없었으며,
  새 디자인 시스템 업로드 전 확인 절차가 있어 업로드/생성은 수행하지 않았습니다.
- design: 디자인 검토 기준의 가독성·우선순위·상태 명확성을 적용해 세 방향을 비교했습니다.
- Stitch Build/SwiftUI: 실제 프론트 또는 네이티브 앱 적용은 시안 선택 이후 범위입니다. 설치는 하지 않았습니다.

Lusion WebGL 화면의 브라우저 직접 캡처는 도구 시간 초과로 완료하지 못했습니다.
공식 페이지 텍스트/공개 실험 설명을 참고했으며, 해당 사이트를 완전히 시각 분석했다고 주장하지 않습니다.
외부 사이트의 코드·스크린샷·이미지·3D 자산을 복사하지 않았습니다.

## 실행과 검증

이 폴더에서 `node serve.mjs`를 실행하면 `http://127.0.0.1:4178/`에서 볼 수 있습니다.
서버는 이 폴더의 허용된 HTML·JS·CSS만 제공하며 외부 네트워크 인터페이스나 금고 저장소를 제공하지 않습니다.
서버 없이 각 HTML 파일을 브라우저에서 열어도 됩니다. 서버 중지는 실행 터미널에서 Ctrl+C입니다.

`node validate.mjs`는 인라인 JavaScript 구문, 중복 ID, 로컬 파일 참조,
자동 외부 자원/저장 API 사용 여부를 검사합니다. 실제 브라우저 클릭·화면 크기·보안 감사의 대체물이 아닙니다.
### 2026-09-11 최종 확인

- `node validate.mjs`: 종료 코드 0, HTML 6개 및 연결된 JavaScript 검사 통과.
- `node --check orbit-globe.js`, `node --check serve.mjs`: 각각 종료 코드 0.
- 웹 인트로: 실제 렌더링, 지구본 움직임 및 일시정지/재생 버튼 전환 확인.
- 모바일 390×844: 인트로 → 금고 진입, 사용처 `Manus` 검색 결과 1개,
  상세 바텀시트 열기/닫기, 합성 키 표시, 연결/금고 탭 이동 확인.
- 모바일 가로 넘침 없음: 문서 폭 390px = 뷰포트 폭 390px.
- 웹·모바일 검사 시 수집된 브라우저 경고/오류 로그 없음.
- 모바일 크기 테스트 후 임시 뷰포트 설정을 해제했습니다.

실제 휴대폰, Safari, 네이티브 앱 빌드, 생체인증, 실데이터 저장·암호화는 검증하지 않았습니다.
모든 기기에서의 성능 및 접근성 전체 검사를 완료한 것은 아닙니다.
