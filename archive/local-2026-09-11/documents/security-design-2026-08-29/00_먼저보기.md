## 이 폴더를 만든 이유

이 폴더는 지금까지의 KeyAtlas 작업을 한곳에서 다시 찾을 수 있도록 만든 **문서 패키지**다. 소스 저장소 자체를 복제한 백업은 아니며, 실제 금고 DB나 비밀번호/API 키를 담는 장소도 아니다.

현재 가장 중요한 상태는 아래 위협 범위의 첫 격리 primitive probe는 구현됐지만, mandatory ordinary suite가 Windows Application Control `4551`로 막혀 전체 Phase 0A 체크포인트가 Inconclusive라는 점이다.

> 같은 Windows 사용자 권한의 별도 프로세스가 잠금 해제 중 SQLite main/WAL/SHM 파일을 조작하는 상황까지 v1에서 방어한다.

이 선택은 “같은 사용자 권한을 가진 완전한 악성코드가 프로세스 메모리까지 자유롭게 읽는 상황을 모두 막는다”는 뜻은 아니다. 이번 경계는 **raw file 조작과 SQLite open 경쟁**을 우선 다룬다.

## 현재 가장 중요한 결론

- 실제 비밀번호, API 키, Secret, 복구 키를 현재 앱에 입력하면 안 된다.
- 현재 저장소는 production-ready 비밀번호 관리자가 아니다.
- SQLite actual main/WAL/SHM 결속과 RO→RW 승격 경쟁이 미해결이다.
- 과거 DB/WAL 전체 rollback과 행 전체 누락 탐지도 미해결이다.
- Windows Phase 0A 격리 probe는 `3f08237`→`fe86fe2`→`6f2cec4`→`e8b29cb`로 구현·보강됐고, 검증 기록은 문서 커밋 `88fd18f`에 저장됐다.
- Phase 0A는 “creator file handle이 닫힌 뒤에도 남는 기존 writable mapping을 차단할 수 있는가” 한 가지 primitive만 시험한다. 최종 후보의 그 단일 실행은 정확한 OS sharing violation 32를 관찰해 primitive Go였지만, 전체 체크포인트 통과는 아니다.
- false-Go를 막기 위해 hostile mapping 전·후 정상 open/read 대조군이 둘 다 성공해야만 primitive Go로 판정한다.
- mandatory ordinary suite가 library test 실행 전에 Windows Application Control 오류 `4551`로 exit `101`이어서 권위 있는 Phase 0A 체크포인트는 **Inconclusive**다. 통합은 중단됐다.
- ordinary suite는 integration test까지 도달하지 못했으므로 최종 후보의 runtime ignored count는 주장하지 않는다. hard gate의 `#[ignore]`는 소스에 남아 있다는 정적 사실만 확인했다.
- `4551`의 직접 원인은 Smart App Control `VerifiedAndReputableDesktop`가 unsigned Rust test EXE를 Enterprise signing 요구 미충족으로 차단한 것으로 확인됐다. 이 원인 확인은 테스트 통과 증거가 아니다.
- 기능 브랜치는 원격과 `f85e547`로 일치하고, `main` 대상 Draft PR `#1`이 열려 있다. Phase 0A의 증거 기반 gate를 통과하기 전에는 Ready 전환과 `main` 병합을 금지한다.
- 다음 선택은 신뢰된 RSA 서명, 전용 Windows 검증 환경, broker/service-boundary 재설계 중 하나다. full VFS/store 통합은 시작하지 않는다.
- Aardvark는 2026-03-06부터 **Codex Security**로 이름과 제공 방식이 바뀌었다. 예전 신청 폼은 열리지만 현재 제품 이용 경로도 함께 확인해야 한다.
